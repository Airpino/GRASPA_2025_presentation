# GRASPA 2025 Presentation

The slides have been presented at the GRASPA SIS meeting of Rome in September 2025.

## GitHub Pages

This presentation is automatically deployed to GitHub Pages. You can view it online at:
`https://airpino.github.io/GRASPA_2025_presentation/`

## Features

- **Interactive presentation** with navigation buttons
- **Keyboard shortcuts** for navigation:
  - `→` or `Space`: Next slide
  - `←`: Previous slide
  - `Home`: First slide
  - `End`: Last slide
  - `F`: Toggle fullscreen
  - `Esc`: Exit fullscreen
- **Touch/swipe support** for mobile devices
- **Responsive design** that works on desktop and mobile
- **Professional styling** with smooth transitions

## Local Development

To run the presentation locally:

1. Clone the repository
2. Open a terminal in the project directory
3. Start a local server: `python3 -m http.server 8000`
4. Open your browser to `http://localhost:8000`

## File Structure

- `index.html` - Main presentation file
- `style.css` - Presentation styling
- `script.js` - Navigation and interaction logic
- `.github/workflows/deploy.yml` - GitHub Actions deployment workflow
