# GRASPA 2025 Presentation

The slides have been presented at the GRASPA SIS meeting of Rome in September 2025.

## 🌐 View Online

This presentation is automatically deployed to GitHub Pages. You can view it online at:

**[https://airpino.github.io/GRASPA_2025_presentation/](https://airpino.github.io/GRASPA_2025_presentation/)**

## 🎮 Controls

- **Arrow Keys** or **Space**: Navigate between slides
- **Home/End**: Jump to first/last slide
- **Escape**: Toggle fullscreen mode
- **Touch/Swipe**: Navigate on mobile devices

## 📁 Structure

- `index.html` - Main presentation file
- `styles.css` - Presentation styling
- `script.js` - Interactive functionality
- `.github/workflows/deploy.yml` - Automated GitHub Pages deployment

## 🚀 Local Development

To view the presentation locally:

1. Clone this repository
2. Open `index.html` in your web browser
3. Or serve it with a local web server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   ```

## 🔧 Customization

You can easily customize the presentation by:

1. **Adding slides**: Add new `<section class="slide">` elements in `index.html`
2. **Styling**: Modify `styles.css` to change colors, fonts, or layout
3. **Content**: Update the slide content directly in `index.html`
4. **Functionality**: Extend `script.js` for additional features

## 📱 Features

- **Responsive Design**: Works on desktop, tablet, and mobile
- **Keyboard Navigation**: Full keyboard support for presentation
- **Touch Support**: Swipe navigation on touch devices
- **Progress Indicator**: Visual progress bar
- **URL Bookmarking**: Direct links to specific slides
- **Print Support**: Print-friendly styling for handouts
- **Fullscreen Mode**: Immersive presentation experience

## 🎨 Customizing Content

To customize the presentation content:

1. Edit the slide content in `index.html`
2. Update the title, subtitle, and author information
3. Add or remove slides as needed
4. Modify the styling in `styles.css` to match your preferences

The presentation will automatically redeploy when you push changes to the main branch.
